# Sterowanie diagnostyką przez USB i EEPROM

Użytkownik wybrał dwie komendy ze wspólną zmianą stanu bieżącego i startowego: DEBUG ON / DEBUG OFF. Dodajemy odczyt DEBUG STATUS. Diagnostyka jest skompilowana domyślnie, ale wyłączona dla pustego EEPROM. Wolny adres 18, wartości A5=ON, 5A=OFF; pozostałe wartości oznaczają OFF. Poprzednie ustawienia 0–17 bez zmian.

Zapis EEPROM w pętli: najpierw eeprom_is_ready, zapis tylko zmienionego bajtu, potwierdzenie SAVED dopiero po zakończeniu i odczycie. Bez czekania na zajęty EEPROM/USB; jedno odroczone potwierdzenie ostatniego stanu, bez kolejki. DEBUG OFF zatrzymuje formatowanie logów od razu.

Ostateczne ustalenie użytkownika: jeden skrypt z menu 1=ON i zapis EEPROM, 2=zapis do pliku, 3=OFF i zapis EEPROM, 0=wyjście. Q i koniec czasu wracają do menu bez zmiany flagi. Żadnego automatycznego OFF ani automatycznej zmiany stanu przy zbieraniu. Opcja 2 sprawdza stan i prosi o 1, jeżeli wyłączony. Reset do logu startowego użytkownik wykonuje przyciskiem po rozpoczęciu zapisu. Samo otwarcie USB może zresetować Mega przez DTR.
